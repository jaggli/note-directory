Notes

Rollback plan lives in deploy.sh. See the architecture drawing.

  • List: note ▾ holds settings, import and export; the big + makes a note and opens it with its name selected.
  • Editor: the name is always on top; tap it for the actions sheet. The key bar adds Tab, ⇧Tab and markdown keys while the keyboard is open.
  • Drawing: the code button is Source; the dock shows the active tool and opens the rest in today's 3×3 sheet.
  • Zen from the actions sheet, or straight away for a read-only link. The name line hides while you scroll down and returns on scroll up; Share and Download float at thumb height; × or swipe back leaves.
  • Long-press a row: the same actions sheet. Help finally tells the truth.
