Title bar and status bar

The title bar is about the note: which one, how you see it, and how it leaves the app. The status bar is about the cursor. Neither holds anything about other notes.

Title bar

Markdown, editing — name and state left, view in the middle, Zen, Share, ⋯ right
Sidebar hidden — the sidebar button appears; unsaved state reads “Edited”
Drawing — Canvas | Source
Any other file — no view switch, no Zen
Renaming — F2, or click the name
Saved, Synced and Syncing… repeat the sidebar footer, so they show only while the sidebar is hidden. Edited, Shared and Read-only are about this note alone and always show.

Status bar

Content changes with the mode; the bar itself never does. Toggles show their state with an accent icon, not just a colour change on a word.
